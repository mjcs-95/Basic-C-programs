# Basic C Programs 🚀

Collection of programs and exercises developed in the C language to review fundamentals, data structures, pointers, matrices, and memory management. 
Following the UCA 13-14 curriculum for the Introduction to Programming course subject.

## 🛠️ Prerequisites
You need a C compiler compatible with C99 (such as `gcc` or `clang`) and optionally `make` installed.

- **Ubuntu/Debian / WSL:** `sudo apt install build-essential`
- **macOS:** `xcode-select --install`
- **Windows:** MinGW or via WSL.
